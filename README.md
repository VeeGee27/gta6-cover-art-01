Magic Hour Cover Studio — turn your photos into multi-panel GTA-style cover art: 9 layouts (including slanted Key Art Slash), poster-formula lettering, sunset and neon grades, crop by dragging, a photo library, Surprise me, and extras (starburst seal, pill badge, stars + quote, tags) — then export a PNG in 1080×1080, 1080×1350 or 1920×1080. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — everything runs offline from your own files; photos never leave your machine.
